# Healthcare Sector Financial Analysis Dashboard

## 📊 Project Overview

An interactive financial analysis dashboard developed using **Power BI, SQL, and Excel** to evaluate and compare the financial performance of leading healthcare companies.

The dashboard analyzes financial data from **FY2021 to FY2025** and presents key financial indicators through interactive visualizations and KPI cards.

## 🎯 Project Objective

The objective of this project is to transform financial statement data into an interactive business intelligence dashboard that helps compare company performance and identify important financial trends.

The analysis focuses on:

- Revenue and revenue trends
- Net profit and profitability
- Return on Equity (ROE)
- Return on Assets (ROA)
- Operating Profit Margin
- Net cash flow
- Total assets

## 🏥 Companies Analyzed

The project covers five major healthcare companies:

- Apollo Hospitals
- Aster DM Healthcare
- Fortis Healthcare
- Krishna Institute of Medical Sciences (KIMS)
- Max Healthcare

**Financial Period:** FY2021 – FY2025

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **SQL** – Data management and analysis
- **Excel** – Data preparation and organization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and financial calculations

## 📈 Dashboard Features

The dashboard provides:

- Interactive company selection
- Financial year filtering
- KPI cards for major financial metrics
- Revenue trend analysis
- Net profit trend analysis
- Net cash flow analysis
- Total asset comparison
- Comparative financial ratio analysis

## 🔍 Key Analysis Areas

### Revenue Analysis
Comparison of revenue performance and trends across the selected healthcare companies.

### Profitability Analysis
Analysis of net profit, ROE, ROA, and operating profit margin to understand profitability.

### Cash Flow Analysis
Evaluation of cash flow trends to understand the movement of cash generated and used by the companies.

### Financial Position
Comparison of total assets to understand the relative financial position and scale of the companies.
